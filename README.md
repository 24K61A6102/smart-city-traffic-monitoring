# Real-Time Traffic Data Processing using Hive, Pig and Streaming Data

## Project Overview
This project implements a smart city traffic monitoring workflow using Hadoop ecosystem technologies.

## Technologies Used
- Hadoop 3.3.6
- Hive 3.1.2
- Pig 0.18.0
- HDFS
- YARN
- Kafka / Streaming
- Ubuntu

## Dataset
Smart City Traffic Monitoring Dataset

## Project Workflow
1. Traffic data collection
2. Streaming data simulation
3. HDFS storage
4. Hive data warehouse
5. Pig data transformation
6. Traffic congestion analysis
7. Traffic hotspot and peak-hour analysis

## Hive
The traffic data is stored in the `traffic_data` Hive table.

## Pig
Pig scripts are used for location-wise traffic aggregation and analysis.

## Results
The project analyzes:
- Traffic congestion levels
- Location-wise traffic volume
- Peak traffic hours
- Average vehicle speed

## Project Architecture
Data Source → Streaming → HDFS → Hive/Pig → Traffic Analytics → Reports
